# XLibrary v0.7.0 — Stability & Reliability

- **Updates:** Stable is the default; Preview is opt-in. GitHub release flags and
  SemVer determine eligibility and ordering. Channel/authentication caches remain
  rate limited; switching channels cancels requests and clears stale installers.
  Installer URL, redirect, size, SHA-256 and toolchain checks are preserved.
- **Tests:** CTest/Qt Test covers release selection, search/ranking, launch identity,
  database constraints/migrations, profile backup and interrupted recovery, bounded
  path search, model lookup and plugin rollback. Linux adds a private D-Bus portal
  protocol fixture. Compiler-matrix CI runs tests, without installing test runtime.
- **Linux Quick Search:** asynchronous GlobalShortcuts portal support with explicit
  denial/unsupported handling and session cleanup. Startup/IPC activation tokens
  are validated and scoped to one activation. Focus diagnostics clear when focus
  arrives. X11 grabs remain supported. System shortcut fallback:
  `XLibrary --overlay` (search), `XLibrary` (library), or editor-provided app/scenario
  commands. Real KDE/GNOME/compositor and multi-monitor acceptance is still required.
- **Search:** directory iteration is cancellable and bounded at 20,000 inspected
  entries and 50 matches. Partial listings offer to open the folder. Application
  icon IDs use a hash index; paint uses precomputed icon keys/kinds and cached fallback.
- **Plugins:** IID 1.0 and Qt major/minor compatibility checks precede instantiation.
  Failed configuration restores factories/styles while preserving the live registry
  address for existing plugins. Errors remain visible and modules can be disabled
  in safe mode. Native plugins are trusted code; segfault/UB cannot be contained.
- **Monitoring:** opt-in local timing exposed expensive availability checks on a
  large synthetic catalog. Process polling stays at 2.5 s; filesystem/volume
  availability checks use 10 s, forced refresh and bounded directory event watches.
  External-drive unavailability never removes cards.
- **Profiles:** SQLite schema remains 8; no new migration or profile format change.
  Existing settings default safely to Stable. Backups preserve catalog relations
  and settings. Russian translations include all new source strings.

Minimum source Qt remains 6.5; Debian packages retain Debian 13 / Qt 6.8.2 /
glibc 2.41. Windows MSVC and MinGW CI remain supported. Version comes exclusively
from `VERSION` through the existing CMake/packaging process. This branch does not
publish a GitHub Release. See [validation](v0.7.0-validation.md) for exact evidence
and outstanding acceptance checks; these notes are not a claim that every platform
and compositor has been tested.
