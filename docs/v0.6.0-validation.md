# v0.6.0: реализация и проверка

Дата: 04.11.2026. База: `684c99c` (v0.5.2). Ветка: `v0.6.0-update`.
Это предрелизный этап к v1.0; версия приложения — 0.6.0.

## Выполнено

- Существующий SearchOverlay: отдельные позиционирование/показ/фокус, полная геометрия до map,
  ограниченная анимация, корректная деактивация и дочерние popup/modal. На X11 передаётся timestamp
  горячей клавиши после окончания passive grab; на Wayland используется Qt requestActivate и
  доступный XDG activation token команды второго экземпляра. Постоянное topmost удалено.
- SearchQuery: ограниченный Damerau–Levenshtein, инициалы и префиксы слов, fuzzy aliases,
  Unicode/layout, общий кэш нормализованных данных для главного окна и оверлея. Relevance
  сравнивается перед избранным. Теги остаются точными; пути и калькулятор сохранены.
- Панель действий оверлея через Tab/Shift+F10 и мышь, существующие редакторы и DesktopService.
  Неприменимые действия скрыты. Удаление подтверждается; ошибка запуска видна в NotificationBanner.
- Типы целей executable/desktop/system_uri/aumid/steam в существующих launch_target и
  launch_configuration; проверка URI и идентификаторов, системная Windows discovery, явное runas.
- Профили Chrome/Edge/Firefox/Brave: обычный/приватный/обнаруженный пользовательский,
  выбор по умолчанию и в сценарии. Существующие аргументы сохраняются; конфликтующие
  режимы не объединяются. Чтение профилей для GUI выполняется в фоновом кэше.
- Глобальные клавиши приложений/сценариев на постоянных ID: центральные конфликты,
  регистрация ОС, прежний зарегистрированный handle сохраняется до успешной записи SQLite,
  каскадное удаление и undo, редакторы и настройки. Wayland: системные команды по ID.
- Steam: локальные VDF/ACF, основная/дополнительные библиотеки, отмена/прогресс в существующем
  асинхронном предпросмотре, идентичность AppID, перенос каталога без потери карточки,
  локальная иконка и запуск через steam://run/AppID. Файлы Steam не изменяются.
- Последовательные миграции 4→5→6→7 с резервной копией, расширенная проверка схемы,
  JSON application catalogs и полные .xlprofile. Прежние миграции не переписаны.
- README, английские исходные строки и русские переводы; нормализация дубликатов alias.

## Проверено в рабочем окружении

Debian 13 x86_64, GCC 14.2, Qt 6.8.2, CMake 3.31.6. Зависимости извлечены из
пакетов Debian 13 в отдельный toolchain; исходники и результаты сборки разделены.

- Полная Linux Debug сборка и встроенный `--check-startup`.
- Проверки на реальных C++ компонентах, временные harness вне репозитория:
  примеры discrod/chrme/vsc/vscode/explrer/stema/пщщпду/alias; все категории рангов;
  теги/исключения, NFC Unicode, calculator/path, ASC/DESC и обновление кэша.
  Каталоги 255 и 1000 записей обрабатывались за 0.20 и 0.67 мс в подготовленном поисковом замере;
  это измерение алгоритма, а не гарантия полной задержки GUI на любом компьютере.
- Xvfb/Openbox X11: вызов глобальной клавишей из активного стороннего окна,
  полная геометрия 680×184 и фокус ввода. Это не проверка KDE.
- QTest с реальными SearchOverlay/SearchResults/DesktopService: QWidget и QWindow события,
  Tab→меню→Escape возвращает ввод, Enter реально запускает тестовый executable,
  ошибка через Enter и меню сохраняет overlay и видимый NotificationBanner.
- Реальный X11 GlobalHotkey: скрытое окно, запуск приложения/сценария, конфликты с
  глобальными/локальными/reserved клавишами, отказ регистрации ОС и ошибка SQLite,
  сохранение старой регистрации, освобождение новой, удаление цели.
- SQLite: restart, unique/FK, undo, старый профиль v4, автоматическая копия миграции,
  Steam libraryfolders старого/нового формата, дополнительные библиотеки, повреждённые
  и неустановленные manifests, отмена, повторный импорт, перенос с сохранением ID/истории/тегов.
- Browser API и реальный callback Manager: параметры всех четырёх браузеров,
  normal/private/user/default/scenario, неизменность custom args, JSON roundtrip.
- ProfileBackup create→inspect→restore→recover: ID приложений/целей/конфигураций,
  typed metadata, история, теги, aliases, сценарии с режимами, shortcuts, настройки и фильтр.
  Неверный fingerprint отвергается до изменения назначения. NFC/case alias dedup проверен.
- MinGW syntax-only для Windows backend; это не MSVC-сборка и не запуск Windows.
- clang-format 18, git diff --check, lupdate/lrelease без незавершённых переводов.

Новые тестовые файлы и тестовая инфраструктура в репозиторий не добавлялись.

## Ограничения проверки перед v1.0

Скриншоты 13818.jpg/13819.jpg не были приложены к этой сессии и не исследованы.
Именно пользовательский дефект KDE здесь не воспроизведён. Причины активации и
прерывания анимации исследованы по коду; успешный Openbox-прогон не заменяет проверки
Plasma/KWin. Версии Plasma/KWin в данном окружении отсутствуют.

Требуются ручные проверки на KDE Plasma/X11, KDE Plasma/Wayland, XFCE/X11 и GNOME/Wayland:
вызов из браузера/файлового менеджера/терминала, fullscreen, все окна свёрнуты и основной
интерфейс в трее; масштабирование, focus/stacking/геометрия. Ограничения compositor соблюдаются.
Для Wayland поддерживается системное сочетание `XLibrary --overlay`; отсутствие разрешённой
активации отображается баннером, без попытки обхода compositor.

Реальные Windows system apps/AUMID, runas/UAC, установленные браузеры и Steam-клиент
на Windows/Linux не запускались в этом окружении. Их аргументы, идентичность, разбор данных
и передача в общий backend проверены отдельно. Нестандартные portable browser data roots
сохраняются через configured arguments; автоматическое обнаружение ориентировано на стандартные каталоги.
