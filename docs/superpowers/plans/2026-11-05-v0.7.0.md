# XLibrary v0.7.0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task-by-task.

**Goal:** Implement the attached stability and reliability specification.
**Architecture:** Extend existing backend and desktop owners. Keep the profile schema and installer security checks unchanged. Use Qt Test with temporary fixtures and no live network.
**Tech Stack:** C++23, Qt >=6.5, CMake, SQLite.
**Spec:** `docs/releases/v0.7.0-spec.md`

## Global Constraints
- Preserve Windows MSVC/MinGW and Linux GCC/Clang support.
- Debian packages use Debian 13, Qt 6.8.2, glibc 2.41.
- Preserve profiles, migrations, import/export, discovery and launcher behavior.
- All new UI strings use the XLibrary translation context and Russian translations.
- Native plugins remain trusted in-process code; safe mode uses built-in UI.
- No release publication. User authorized commits and pushes to v0.7.0-update.

## Review Focus
- Malformed release JSON and channel changes during active checks must not expose stale installers.
- Cancelled path requests must stop traversal and never replace newer results.
- Missing application IDs and model resets must not use stale rows.
- Plugin exceptions must not publish partial registry configuration.
- Old profiles and backup failures must preserve data and relationships.
