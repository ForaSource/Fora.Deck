# Поиск файлов и использование — 0.8.0

Цель: исправить и ускорить поиск в существующей ветке v0.8.0-update с сохранением дисков, масок, своих файлов и остальных возможностей.

- [x] FileManager: обход в ширину с приоритетными Desktop/Documents/home внутри заданного охвата; кэш подготовленных имён; прямой поиск до опечаток; проверка содержимого только финальной выдачи.
- [x] ProfileSchema/Database/CatalogTypes: миграция v8 → v9, счётчики запусков и открытий, очистка истории с сохранением undo.
- [x] SearchResults/DesktopService/LibraryModel/LibraryViews: единый порядок релевантность → избранное → использование → расположение/глубина; учёт успешных действий, сортировка своих файлов и прямого просмотра папки; debounce 100 мс.
- [x] Версия 0.8.0 сохранена; документация и русские переводы обновлены.
- [x] Итоговая Linux Debug-сборка, CTest 6/6, --check-startup и ручная проверка поиска и миграции.
- Публикация: коммит и обычный push без force в v0.8.0-update.

Используется существующий FileManager и SQLite-индекс. История хранится в основной БД профиля и полной резервной копии. Сохраняется установленная фильтрация файлов и настройка корней. Новые тесты не пишем согласно AGENTS.md.

Проверено на временных профилях: поиск маской; приоритет Documents после повторного открытия; сохранение счётчиков приложения и файлов; миграция v8 → v9 с автоматической резервной копией; пополнение результата после отбраковки30 файлов, ставших бинарными после индексации. Ревью выявило и исправлено: выход preferred-корней через ссылки, вытеснение кэша при числе имён >20000, потеря выдачи после финальной фильтрации. Windows и упаковка не проверялись.
